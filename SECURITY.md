# Security policy

## Supported version

Servara 1.0 is the currently published technical preview.

## Report a vulnerability

Submit security vulnerabilities through
[GitHub private vulnerability reporting](https://github.com/amrithasb/servara/security/advisories/new).
Do not include passwords, vault contents, personal records, or sensitive vulnerability details in a
public issue.

General questions that do not contain sensitive information may be submitted through
[GitHub Issues](https://github.com/amrithasb/servara/issues).
