PRIVACY

Privacy overview

Technical preview · Version 1.0

The short version

Servara is designed as a local-first desktop application. The technical preview stores vault content on the user’s computer and includes no advertising, analytics, tracking pixels, or remote crash-reporting service.

Information stored by the application

Information entered into the owner vault, supported imported documents, settings, and activity history are stored locally. Vault content and attachment bytes are encrypted at rest. A small local header contains versioned encryption metadata but not the master password.

Network behavior

The packaged technical preview blocks ordinary external network requests. Optional shared-vault functionality remains unavailable unless production cloud infrastructure is explicitly configured in a future build.

Exports and backups

Encrypted Servara backups remain protected by the applicable vault password. Emergency-summary PDFs, printed pages, screenshots, and deliberately exported document copies are plaintext and outside Servara’s protection. Trusted Access packages are separately encrypted and reveal limited manifest metadata before unlock.

Website privacy

This static website contains no cookies, analytics, account forms, advertising, or tracking scripts. A future hosting provider may retain ordinary server request logs under its own infrastructure policy.

Technical-preview limitation

Servara has not received an independent privacy or security audit. Those reviews and a public support process remain release requirements.
